Kit ZAMAP Carro

Tratamento combinado para o motor

Kit que reúne Petrol Max para o combustível e Maxitec para o óleo do motor. Combina tratamento do sistema de injeção e redução de atrito em uma solução para carros.

Principais benefícios

  • ✓Tratamento do combustível
  • ✓Redução de atrito
  • ✓Proteção combinada
Consultar este produto

Indicação

Carros compatíveis com os dois produtos do kit.

Modo de uso

O kit utiliza Petrol Max no tanque de combustível e Maxitec no óleo do motor. Cada componente deve ser aplicado no seu respectivo sistema, conforme dosagem e compatibilidade indicadas no rótulo.
